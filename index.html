Personal backup utility

Spark2 Recovery Pilot

Encrypted backups to the owner's Google Drive, with integrity checks and isolated restore testing.

What the application does

Spark2 Recovery Pilot uses Restic and rclone to encrypt selected local files, upload the encrypted repository directly to the owner's Google Drive, and download repository data to check integrity and test restoration. The current pilot uses a small, generated, nonsecret test fixture.

This is a personal application for its operator. It is not a public backup service and does not offer account registration.

Google Drive access

The application requests the drive.file permission to create and manage its own repository files and folders. It does not request access to all existing Drive files. Google authorization is completed through Google's sign-in and consent screens.

This informational website does not accept credentials, upload backups, or provide access to the repository.
