Spark2 Recovery Pilot

Privacy policy

Effective October 15, 2026.

Purpose and information used

This personal backup utility is operated by the Google account owner. It accesses the contents and metadata of Drive files created by or explicitly authorized for this application under Google's drive.file permission. It uses that access only to store encrypted backup repository objects, maintain repository metadata and locks, check integrity, and restore files at the operator's direction. The current pilot backs up only a generated nonsecret fixture.

Storage and protection

Selected source files are encrypted locally by Restic before upload to Google Drive. OAuth credentials are stored in private local configuration on the operator's machine. Repository passwords are kept separately from the uploaded repository. This public website and its source repository contain no backup data or OAuth credentials.

Sharing and use

The application transfers encrypted repository data to Google Drive and retrieves it to the operator's machine. It does not sell Google user data, use it for advertising, share it with unrelated third parties, or use it to train generalized AI or machine-learning models. Its use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and control

Backup objects and local evidence remain until the operator explicitly chooses to delete them. Revoking this application's access through Google Account permissions stops its authorized access; revocation does not itself erase stored backups. The operator can manage stored repository files in Google Drive and private local copies directly.

This website

This is a static information site with no application analytics, advertising, forms, or sign-in. GitHub hosts it and may process request information under its own privacy statement.

Contact and changes

Contact the maintainer through the public issue tracker. Never include private data or secrets. Material changes to the application's data practices will be reflected here before those practices change.
